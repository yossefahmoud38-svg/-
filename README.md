# مسجد أبو بكر الصديق

مشروع Flutter عربي مبدئي لإدارة المسجد. يتضمن الحسابات المالية والتسجيل المحلي وبعض أقسام الإدارة.

## بناء APK من GitHub

1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub (وليس ملف ZIP نفسه).
2. افتح تبويب Actions في المستودع.
3. اختر workflow باسم Build Android APK ثم اضغط Run workflow.
4. بعد انتهاء التشغيل بنجاح، افتح التشغيل ثم نزّل Artifact باسم `masjid-abu-bakr-apk`.
5. فك ضغط Artifact وستجد `app-release.apk`.

ملاحظة: هذه العملية تبني APK في GitHub Actions. يجب مراجعة نتيجة البناء واختبار التطبيق على الهاتف قبل الاعتماد عليه. البيانات المحلية قد تُفقد عند حذف التطبيق؛ لا يوجد نسخ احتياطي سحابي مفعّل في هذه النسخة.
